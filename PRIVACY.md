# Privacy

## Public listing

The public listing contains only event information supplied for publication: title, optional team label, prefecture, city, public venue, optional public HTTPS venue URL, date and time, level, fee, available positions, equipment, cancellation rule, access note, and public note.

## Private data

Organizer join instructions are returned only to an accepted applicant who presents the application capability. Applicant position, experience, short note, and status are returned only to the organizer or that applicant. Raw capability tokens are stored only in URL fragments; D1 stores their SHA-256 hashes.

The service does not request or store names, email addresses, telephone numbers, ages, gender identities, account handles, photographs, exact private addresses, payment details, or message threads.

## Telemetry and retention

Anonymous operation events contain a random browser identifier, event name, listing identifier when relevant, and JST date. Events expire after 45 days. Listings, applications, and reports expire within 30 days after the event. Automated QA is excluded.
